# لوحة مبيعات المتجر الإلكتروني

لوحة تفاعلية مبنية بـ Streamlit و Plotly، تعرض أداء متجر إلكتروني للأجهزة والإكسسوارات وتساعد على معرفة أين نركّز النمو.

## وصف اللوحة والبيانات

- **البيانات:** 500 طلب مولّدة بالكود (بذرة عشوائية ثابتة `seed=10` فتتكرر نفس النتائج في كل تشغيل)، من 2023-01-01 إلى 2024-12-31.
- **الأعمدة:** تاريخ الطلب، المنتج (8 منتجات)، الكمية، المدينة (عمان، إربد، الزرقاء، العقبة)، رقم العميل (99 عميل فريد)، الفئة (Electronics / Accessories)، سعر الوحدة، والإيراد = الكمية × السعر.
- **الفلاتر (الشريط الجانبي):** نطاق التاريخ، الفئة، المدينة (مع خيار "الكل"). كل المؤشرات والرسومات والجداول وقسم الملاحظات تتحدث مع الفلاتر.

## المؤشرات الأربعة ولماذا اخترناها

| المؤشر | لماذا هو Actionable وليس Vanity Metric |
|---|---|
| إجمالي الإيراد | يقارن أداء الفترات والمدن والفئات، فنعرف أين نزيد الإنفاق التسويقي وأين نعالج الضعف. |
| عدد الطلبات | يفصل بين "نحتاج زبائن أكثر" و"نحتاج سلة أكبر"، وإذا نزل نراجع الحملات. |
| متوسط قيمة الطلب | يوجّه قرارات العروض (حزم، شحن مجاني فوق مبلغ معيّن) لرفع قيمة السلة بدون جلب زبائن جدد. |
| عدد العملاء الفريدين | يقيس اتساع قاعدة الزبائن الحقيقية، وإذا كان قريباً من عدد الطلبات فالمشكلة في الولاء فنبني برنامج ولاء. |

## طريقة التشغيل

1. تثبيت المكتبات (مرة واحدة):

   ```
   pip install streamlit plotly pandas numpy
   ```

2. تشغيل اللوحة من مجلد الملف:

   ```
   streamlit run dashboard.py
   ```

3. يفتح المتصفح تلقائياً على العنوان `http://localhost:8501`.

## أهم 3 رؤى (للفترة كاملة بدون فلاتر)

1. **عمّان أكبر سوق:** تمثل 49.3% من الإيراد، بينما العقبة 15.3% فقط، والفرصة حملات موجهة للمدن الأضعف.
2. **الإلكترونيات تصنع الإيراد:** فئة Electronics تحقق 90.6% من الإيراد، وLaptop وTablet وحدهما 74.5% (135,700 من أصل 182,160 دينار). والخطر هو الاعتماد على منتجين.
3. **قاعدة العملاء موزعة:** أفضل 5 عملاء يمثلون 18% فقط من الإيراد، فلا يوجد اعتماد خطير على عميل واحد، ويمكن إطلاق برنامج ولاء لتكرار الشراء.

**ملاحظة إضافية:** أعلى شهر إيراداً كان كانون الأول 2023 بقيمة 14,425 دينار، وأقل شهر شباط 2024 بقيمة 1,990 دينار.
